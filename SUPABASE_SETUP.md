# Подключение регистрации и личных аккаунтов

## 1. Создать проект Supabase

Создайте проект на https://supabase.com и откройте **Project Settings → API**.

Скопируйте:

- Project URL;
- публичный `anon` / publishable key.

Секретный `service_role` ключ в сайт добавлять нельзя.

## 2. Настроить переменные

Скопируйте `.env.example` в `.env` и подставьте полученные значения:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_ANON_KEY
```

После изменения `.env` перезапустите Vite.

## 3. Создать таблицы и политики

В Supabase откройте **SQL Editor**, вставьте содержимое файла
`supabase/migrations/20260930175159_create_fitness_learning_progress.sql`
и нажмите **Run**.

Затем таким же способом запустите:
`supabase/migrations/20261003000100_add_course_access_approval.sql`.

Миграция создаёт:

- профиль для каждого нового пользователя;
- отдельный прогресс уроков для каждого аккаунта;
- RLS-политики, запрещающие пользователям видеть чужие данные.
- отдельное безопасное подтверждение доступа после регистрации.

## 4. Подтверждать оплативших

Новый пользователь может зарегистрироваться сам, но до подтверждения увидит
экран ожидания.

Чтобы открыть ему платформу:

1. Откройте **Table Editor → course_access**.
2. Найдите строку пользователя по `email`.
3. Поставьте `is_approved` в `true`.
4. При желании укажите дату окончания в `access_expires_at`.

Пользователь нажимает **Проверить доступ** и сразу попадает в платформу.

## 5. Настроить адрес сайта

В **Authentication → URL Configuration** укажите адрес опубликованного сайта как
`Site URL`. При необходимости добавьте локальный адрес `http://localhost:5173`
в Redirect URLs.

После этого регистрация, подтверждение email, вход, выход, профиль и прогресс
работают через личный аккаунт пользователя.
